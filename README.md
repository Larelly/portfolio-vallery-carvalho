# Portfólio — Vallery Carvalho

Portfólio pessoal (currículo online) desenvolvido como Atividade Prática da
disciplina **Fundamentos da Programação Web** — Análise e Desenvolvimento de
Sistemas, UNINTER.

**Site publicado:** https://larelly.github.io/portfolio-vallery-carvalho/

## Tecnologias

- HTML5 semântico
- CSS3 puro (sem Bootstrap, Tailwind ou qualquer framework)
- JavaScript puro (sem React, jQuery ou bibliotecas externas)

## Estrutura

```
portfolio-vallery-carvalho/
├── index.html          Página única com as 4 seções
├── css/
│   └── estilo.css      Estilos, temas claro/escuro e responsividade
├── js/
│   └── script.js       Menu, tema, validação e modal
├── img/                Imagens do projeto
└── README.md
```

## Seções

1. **Sobre mim** — apresentação, áreas de atuação, tecnologias e hobbies
2. **Formação** — linha do tempo acadêmica, cursos e idiomas
3. **Portfólio** — trabalhos realizados com link para o código
4. **Contato** — formulário com validação em JavaScript e simulação de envio

## Funcionalidades em JavaScript

- Validação dos campos nome, e-mail (formato `usuario@dominio.com`) e mensagem
- Simulação do envio: limpeza dos campos e modal "Mensagem enviada com sucesso!"
- Alternância entre tema claro e escuro, com a preferência salva no navegador
- Menu responsivo para celular
- Destaque automático do link da seção que está sendo lida
- Contador de caracteres da mensagem
